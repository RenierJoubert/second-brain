# Non-homogeneous Systems

A non-homogeneous system has the form:
$$
\vec{x'}(t) = A(t)\vec{x} + \vec{f}(t)
$$
Where $\vec{f}(t) \neq 0$. Similarly to [[2.5 Non-homogeneous Equations]], we can use:
$$
\vec{x}(t) = \vec{x}_{p}(t) + \vec{x}_{c}(t)
$$
to construct our general solution, where $\vec{x}_c$ solves the associated homogeneous system $\vec{x'}=A\vec{x}$ and $\vec{x}_p$ is some particular solution.

## Variation of Parameters

Suppose we solved the associated homogeneous system $\vec{x'}=A \vec{x}$ and found the fundamental matrix solution $X(t)$ from [[3.3 Linear Systems of ODEs]]. Then, the complementary solution has the form:
$$
\vec{x}_{c} = X(t)\vec{c}
$$
And we can solve for $\vec{x}_p$ using the formula:
$$
\vec{x}_{p} = X(t) \int[X(t)]^{-1} \vec{f}(t)dt
$$
Note that this works even when $A$ depends on $t$.

## Undetermined Coefficients

If $A$ is a constant matrix, we can instead find $\vec{x}_p$ by guessing its form based on $\vec{f}(t)$ with some unknown constant vectors, then substituting it into the system and solving for those constants.

If $\vec{f}(t)$ is a polynomial of degree $n$, then we guess a vector polynomial of degree $n$:
$$
\vec{x}_{p}(t) = \vec{a}_{n}t^n + \vec{a}_{n-1}t^{n-1} + \cdots + \vec{a}_{0}
$$
If $\vec{f}(t) = \vec{b}e^{ \lambda t }$ is exponential, then we guess:
$$
\vec{x}_{p}(t) = \vec{c}e^{ \lambda t }
$$
If $\vec{f}(t) = \vec{b}\cos(\omega t) + \vec{d}\sin(\omega t)$, then we guess:
$$
\vec{x}_{p}(t) = \vec{c}\cos(\omega t) + \vec{e}\sin(\omega t)
$$
Where even if $\vec{f}(t)$ only has a cosine, it is safest to include both cosine and sine in the guess.

Finally, if $\vec{f}(t)$ is an exponential times a polynomial or trig function, then we guess the same general type. For example, if $\vec{f}(t) = \vec{b}e^{ \lambda t }\cos(\omega t)$ then we guess:
$$
\vec{x}_{p}(t) = e^{ \lambda t }(\vec{c}\cos(\omega t) + \vec{d}\sin(\omega t))
$$

### Edge Cases

Just like in [[2.5 Non-homogeneous Equations]], if our guess for $\vec{x}_p$ overlaps with part of $\vec{x}_c$ then the guess fails, so we multiply by $t$. However, unlike single equations, ==we also need to keep the lower order terms==. For example, if $\vec{f}(t) = \vec{b}e^{ \lambda t }$ and $\lambda$ is an eigenvalue of $A$, then we guess:
$$
\vec{x}_{p}(t) = (\vec{a}t + \vec{c})e^{ \lambda t }
$$
