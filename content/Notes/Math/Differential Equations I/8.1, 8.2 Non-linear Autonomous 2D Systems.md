# Non-linear Autonomous 2D Systems

So far we have only dealt with linear systems $\vec{x'}=A\vec{x}$, but now consider a non-linear system of the form:
$$
\begin{cases}
x' = F(x,y) \\
y' = G(x,y)
\end{cases}
$$
Where, just like in [[1.6 Autonomous Equations]], the system is *autonomous* because $F$ and $G$ do not depend on $t$. We usually can't solve these explicitly, so instead we study the *phase plane*, namely, the $xy$-plane together with the trajectories showing how solutions move through it.

## Nullclines

The *nullclines* are the curves where one of the derivatives is zero. That is, the $x$-nullcline is the curve $F(x,y)=0$ where $x'=0$, so trajectories crossing it only move up or down. Similarly, the $y$-nullcline is the curve $G(x,y)=0$ where $y'=0$, so trajectories crossing it only move left or right.

In essence, the nullclines split the plane into regions where the signs of $F$ and $G$ don't change. So, by checking the sign of $F$ and $G$ in each region we can sketch the direction field, where $x'>0$ means arrows point right and $x'<0$ left, whereas $y'>0$ means arrows point up and $y'<0$ down.

## Critical Points

A *critical point* (or *equilibrium*) $(x^*,y^*)$ is a point where both derivatives are zero such that:
$$
F(x^*,y^*)=0 \quad \text{and} \quad G(x^*,y^*)=0
$$
Namely, the critical points are exactly where the $x$ and $y$ nullclines intersect. A solution starting at a critical point has $x'(t)=y'(t)=0$, so it stays there forever.

## The Jacobian

To study the system near a critical point we use the *Jacobian matrix*:
$$
J(x,y) = \begin{bmatrix}
F_{x}(x,y) & F_{y}(x,y) \\
G_{x}(x,y) & G_{y}(x,y)
\end{bmatrix}
$$
Then, evaluating it at a critical point gives us $A=J(x^*,y^*)$, which is the best linear approximation of the system near $(x^*,y^*)$.

## Linearization

Let $u$ and $v$ be small perturbations away from a critical point such that:
$$
x = x^* + u \quad \text{and} \quad y = y^* + v
$$
Then, near $(x^*,y^*)$ the non-linear system is approximated by the linear system:
$$
\begin{bmatrix}
u' \\
v'
\end{bmatrix}
= J(x^*,y^*) \begin{bmatrix}
u \\
v
\end{bmatrix}
\iff \vec{u'} = A\vec{u}
$$
This is called the *linearization* of the system at $(x^*,y^*)$. It works because $F(x^*,y^*)=0$, so the first order Taylor expansion of $F$ about the critical point is just $F_{x}u+F_{y}v$ (and similarly for $G$).

In brief, close to a critical point the phase portrait looks like the phase portrait of $\vec{u'}=A\vec{u}$, which we already know how to handle from [[3.3 Linear Systems of ODEs]].

## Classifying Critical Points

To classify an isolated critical point we find the eigenvalues $\lambda_{1}, \lambda_{2}$ of $A=J(x^*,y^*)$ and use the same pictures as in [[3.5 2D Systems and Vector Fields]].

If the eigenvalues are real with opposite signs, $\lambda_{1}<0<\lambda_{2}$, then the critical point is a *saddle*, which is always unstable. If they are real with the same sign it is a *node*, namely, a stable node (*sink*) if both are negative and an unstable node (*source*) if both are positive.

Whereas if the eigenvalues are complex, $\lambda=\alpha \pm i\beta$ with $\beta \neq 0$, then it is a *spiral*, which is stable if $\alpha<0$ and unstable if $\alpha>0$. Finally, if they are purely imaginary, $\lambda=\pm i\beta$, then the linearized system has a *center*.

Note that for the non-linear system the center case is inconclusive.

## The Trace-Determinant Test

For a $2 \times 2$ Jacobian we can classify a critical point without finding the eigenvalues. Let:
$$
A = \begin{bmatrix}
a & b \\
c & d
\end{bmatrix}
\quad \text{s.t.} \quad \tau = \text{tr}(A) = a+d \quad \text{and} \quad \Delta = \det(A) = ad-bc
$$
Then, the characteristic equation is:
$$
\lambda^2 - \tau\lambda + \Delta = 0
$$
With discriminant $D=\tau^2-4\Delta$. This works because $\lambda_{1}\lambda_{2}=\Delta$ and $\lambda_{1}+\lambda_{2}=\tau$.

So, if $\Delta<0$ the critical point is a saddle. If $\Delta>0$ and $D>0$ it is a node, and if $\Delta>0$ and $D<0$ it is a spiral, where in both cases $\tau<0$ means it is stable and $\tau>0$ means it is unstable. If $\Delta>0$ and $\tau=0$ the linearization is a center. Otherwise, if $\Delta=0$ or $D=0$ we have a zero or repeated eigenvalue and need to check more carefully.

## Stability

Similar to [[1.6 Autonomous Equations]], a critical point $(x^*,y^*)$ is *stable* if solutions starting sufficiently close to it stay close for all future time, and *unstable* if there are solutions starting arbitrarily close to it that move away.

Furthermore, it is *asymptotically stable* if it is stable and solutions starting close enough also converge to it such that:
$$
\lim_{ t \to \infty } (x(t),y(t)) = (x^*,y^*)
$$
In terms of eigenvalues, if all the eigenvalues of $J(x^*,y^*)$ have negative real part then the critical point is asymptotically stable. Whereas if at least one eigenvalue has positive real part it is unstable.

## When Is Linearization Inconclusive?

Linearization only works when the critical point is *hyperbolic*, namely, when no eigenvalue of $J(x^*,y^*)$ has real part zero. So, if we get an eigenvalue like $\lambda = \pm i\beta$ or $\lambda=0$, then the non-linear terms we dropped can change the behaviour completely.

For example, the linearization might be a center but the non-linear system could actually be a stable spiral, an unstable spiral, or something more complicated. In these cases we need to consider nullcline analysis, invariant regions, or conserved quantities.

## Limit Cycles

A *limit cycle* is an isolated closed trajectory in the phase plane. Closed means the motion is periodic, and isolated means the nearby trajectories are not also closed curves. It is a *stable limit cycle* if nearby trajectories spiral towards it and an *unstable limit cycle* if they spiral away from it.

In essence, a linear system with a center has infinitely many closed orbits nested inside each other, so none of them are isolated. Whereas a non-linear system can have a single isolated periodic orbit, so ==limit cycles only show up in non-linear systems==.

## Workflow

Given some system $x'=F(x,y)$ and $y'=G(x,y)$:

1. Find the nullclines $F(x,y)=0$ and $G(x,y)=0$.
2. Find the critical points by solving both equations simultaneously.
3. Use the signs of $F$ and $G$ in each region to find the arrow directions.
4. Compute the Jacobian $J(x,y)$ and evaluate it at each critical point $A=J(x^*,y^*)$.
5. Find the eigenvalues of $A$ (or use the trace-determinant test) and classify each critical point.
6. Combine the local pictures with the nullclines and direction field to sketch the phase portrait.
7. If linearization is inconclusive, rely on nullclines, invariant regions, conserved quantities, or other theory.
