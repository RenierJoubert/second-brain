j \*(rd) vs j (rd)

j a is for when we have the address (ie something static and global), ie a is a label known at compile time

j o(rd) this doesnt read memory, this is is used when the function address is already in a register (we usually dont use offset)

j \*o(rd) is for when the function is a pointer that is in a struct or array and rd is the base

j \*(r1, r2, 4) is similar
